# Spring Boot WebSocket + STOMP Reference

These files (`WebSocketConfig.java`, `ChatMessageController.java`, and `static/index.html`) are reference templates for a **Spring Boot (`spring-boot-starter-websocket`)** application.

They live separately from `codes/` so the pure-JDK labs in `codes/` compile cleanly with standard `javac` without requiring Spring Boot JARs on the classpath.
